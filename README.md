# Google Maps Business Scraper (Lalitpur)

Automated Selenium-based scraper to collect pharmacy and cosmetic store data from Google Maps in Lalitpur, Nepal.

## Features
- Extract business name, phone number, and Google Maps link
- Supports multiple areas and keywords
- Removes duplicate entries automatically
- Saves data to Excel
- Resume capability

## Installation

```bash
pip install -r requirements.txt

```
